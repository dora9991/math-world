## 4択への変換（呼び出し側 `src/engine/mathLaboProblems.js`）

- 中1は答え(`ans`)が常に数値で、`choices`は数学ラボ2側から提供されない
  → math-world側が正解の近くの数値から機械的に4択を作る。
- 中2・中3は数学ラボ2側が既に `exprChoices`/`numChoices` で本物の誤答
  パターンから4択(`choices`)を作ってくれているものが多い（式の答え・因数分解の
  答え・用語など）ので、それがあればそのまま使う。答えが単純な数値のみで
  `choices` が無い問題（角度・関数の値など）は中1と同じ数値フォールバックを使う。
