## なぜ別リポジトリなのか（2026-08-11の決定）

> 保守2倍を1.2倍に落とす方法は1つしかない。共有するのはデータだけ。エンジンもUIも共有しない。

数学ラボ2は学校配布用の学習アプリとして無償で残す。ゲーム特化版はそれとは別の"2本目"。
この2つのソースコードを同じリポジトリに置かない、というのがこのリポジトリを分けた理由。

（2026-09-11の経緯：`gachaRoster.js`/`growthCurve.js` が誤って数学ラボ2リポジトリの
`src/data/` に作成されていたのを発見し、`math-labo-game`という仮名で別リポジトリへ移設。
同日、`math world`へ改名し、実際に動くプロトタイプの実装を開始した。）

## 現在の中身（2026-09-11時点・Vite + React のWebプロトタイプ）

- `src/data/gachaRoster.js` — 既存モンスター図鑑（240→205体）をN/R/SR/URに再編集した下ごしらえデータ。5パラメータ（計算/方程式/関数/図形/データ）をゼロサムで保持。中1第7章（確率を含むデータの活用まで）・各小単元ボス・章ボス・大ボス（数学の魔王）が揃っている。
- `src/data/growthCurve.js` — レア度別レベル上限（N=30/R=40/SR=50/UR=70）とレベル成長カーブ（線形・レベル1=上限値の30%〜レベル上限=100%）。
- `src/data/storyMap.js` — 上記データを「学年→章→小単元」の地図構造に組み立てる。
- `src/engine/` — 問題生成（章ごとの簡易4択）・戦闘計算（クリティカル式）・ガチャ・EXP→レベル換算。
- `src/context/GameContext.jsx` — セーブデータ（localStorage）とゲーム内アクション。
- `src/screens/` — オープニング→タイトル→メニュー→ストーリー（学年マップ→章マップ→小単元選択→戦闘→報酬→ガチャ）→パーティ編成。学習モード・タッグクエスト・設定は画面だけのスタブ。
