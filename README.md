# math-labo-game（仮称）

数学ラボの「ゲーム特化版」（Unity構想、家庭・娯楽向け）専用のリポジトリ。
**数学ラボ2（math-labo-second・学校の授業/課題用・永久無償）とは別リポジトリ。**

設計の経緯・決定はすべて Obsidian Vault 側に記録している：
`10_Projects/math-labo/設計_ゲーム特化版_Unity構想_2026-08-11.md`

## なぜ別リポジトリなのか（2026-08-11の決定）

> 保守2倍を1.2倍に落とす方法は1つしかない。共有するのはデータだけ。エンジンもUIも共有しない。

数学ラボ2は学校配布用の学習アプリとして無償で残す。ゲーム特化版はそれとは別の"2本目"。
この2つのソースコードを同じリポジトリに置かない、というのがこのリポジトリを分けた理由。
共有していいのは問題データ（`math-problems/`、未着手）だけで、
モンスター/ガチャ/レベル成長のようなゲーム側だけのコンテンツは共有対象にすら入らない。

（2026-09-11の経緯：`gachaRoster.js`/`growthCurve.js` が誤って数学ラボ2リポジトリの
`src/data/` に作成されていたのを発見し、このリポジトリへ移設した。）

## 現在の中身

- `data/gachaRoster.js` — 既存モンスター図鑑（240→205体）をN/R/SR/URに再編集した下ごしらえデータ。5パラメータ（計算/方程式/関数/図形/データ）をゼロサムで保持。
- `data/growthCurve.js` — レア度別レベル上限（N=30/R=40/SR=50/UR=70）とレベル成長カーブ（線形・レベル1=上限値の30%〜レベル上限=100%）。

まだ実際のゲーム画面・エンジンは無い（データの下ごしらえのみ）。実装スタック（Unity/Web等）は8/11ノートの#todoのまま未確定。
